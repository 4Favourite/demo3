# ELEVARE — Above the weather

A single-file, scroll-driven luxury-tower website. No build step: open `index.html`.

## Segments
1. **Hero** — night-sky gradient, drifting clouds, twinkling stars + shooting stars, glitching barcode skyline
2. **Reveal** — scroll-scrubbed sunset → sky transition with the windowed-skyline ELEVARE wordmark
3. **Vision** — word-by-word headline, count-up stats (68 / 142 / 246 m / 2027), ticker
4. **Residences** — "Two floors are a kind of quiet": accordion gallery of 5 B&W interiors with 3D tilt
5. **Views** — "The view by day. And after dark.": draggable day/night split + cursor lens
6. **Promise** — hand-drawn underlines, self-drawing signature, SEALED stamp, rising skyline
7. **Contact** — viewing request form with confetti, loops back to the hero

## Extras
Loader that counts up to floor 68 · live floor/altitude HUD · scroll progress bar · custom cursor + magnetic buttons ·
**Showreel** auto-scroll mode (`P`) · command palette (`⌘/Ctrl+K` or `/`) · **Clean mode** (`H`) hides UI for screen recording ·
add `?skip` to the URL to skip the loader.
